Group research project · TU Delft

LLM annotation panel

Can a panel of language models that learn from each other's annotations label creative thinking in meetings more consistently?

Overview

This project researches creativity annotation in real meeting transcripts with a panel of large language models, inspired by panel-of-experts and active learning set-ups. Four models (GPT, Gemini, Mistral and Llama via Groq) label transcripts from the QMSum dataset against a fixed codebook of eight creative-thinking types, each with a definition and an example.

Set-up

  • Two conditions. In the baseline, each model annotates on its own. In the feedback condition, the other models' previous annotations are injected into the prompt as few-shot examples.
  • Prompts. Built from the codebook and requesting pure JSON output, which is parsed and checked before scoring.
  • Agreement. Scored with pairwise F1 between models over repeated runs.
  • Statistics. The conditions were compared with paired t-tests after Shapiro-Wilk normality checks.

What it showed

The main lesson was that agreement is not accuracy: a panel can converge on the same wrong label. An automated annotator needs a small human-verified set to calibrate against before it is trusted at scale.

Code

The pipeline is modular: preprocessing of the transcripts, the iterative annotation experiment, post-processing into structured results with agreement scores, aggregation and plots over runs, and a separate statistical analysis script. New models can be added to the panel by registering a wrapper.
