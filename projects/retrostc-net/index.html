RetroSTC-Net

Can an event that happens after learning decide whether a network keeps what it learned? Retroactive consolidation for neural networks, based on synaptic tagging and capture.

Background

According to the synaptic tagging and capture (STC) hypothesis (Frey and Morris, 1997), learning first causes a short-lived synaptic change and leaves a temporary tag. The change becomes permanent only if plasticity-related products arrive while the tag is still present, and these can be triggered by a separate salient event. Behaviourally, an unfamiliar experience shortly before or after weak learning makes the weak memory last.

This project implements that mechanism in standard backprop-trained networks, tests whether the behavioural-tagging time window appears, and uses the network's own consolidation record as an explanation of what it remembers. The motivation is that methods such as Elastic Weight Consolidation (EWC) and Synaptic Intelligence fix a weight's importance at the time of learning, whereas in many applications importance only becomes clear later, for instance when a fraud label or a user correction arrives. Whether retroactive consolidation helps in that setting is not tested here.

Contribution

Related mechanisms exist, such as a decaying weight component with tag-and-capture against forgetting (Leimer, Herzog and Senn, 2019), two-component weights in a backprop MLP consolidated by the size of the change (Li and van Rossum, 2020), and retroactive STC in spiking networks (Lehr, Luboeinski and Tetzlaff, 2022). What this project adds:

  • consolidation in a backprop-trained network that is decided retroactively, by a salience event occurring after learning;
  • a behavioural-tagging time-window test in network weights, including rescue of one task by another;
  • a consolidation log that explains what the network retained, validated with a faithfulness test.

Method

Each weight is split into a consolidated part L and a labile part E, with effective weight w = L + E. The optimiser updates w as usual, so ordinary training code is unchanged; after each step the change is moved into E and:

Early-phase LTP decaysE ← E · exp(−1/τE)τE = 1000 steps
Synaptic tagh ← h · exp(−1/τh) + |Δw|τh = 150 steps
Plasticity-related products, shared per neuronp ← p · exp(−1/τp) + α·s(t)τp = 80 steps
Capturec = clamp(κ · p · [h > θ], 0, 1), then L += c·E, E −= c·Eκ = 0.05, θ = 10⁻³
Salient events(t): a pulse, or a sudden jump in training loss

Without an event nothing is captured and every learned change decays away. Capture needs a tag and products at the same step, which is what creates a time window around the event. In the default mode every unit receives the same pulse, so the products act as one global signal and the tags decide where capture happens. Two variants serve as ablations: products made only at synapses tagged at event time, and a separate tag for each learning episode's change instead of one per weight.

Labile change is tracked per learning episode, so every consolidated change can be traced to the task that produced it and the event that captured it; the event attribution is exact when events do not overlap within the products' lifetime. Unit tests check, among other things, that the consolidated changes per episode add up exactly to the weight change.

The main measure is the share of a task's learning that became permanent, the consolidated change projected onto the task's total change, Σ(consolidated · change) / Σ(change²), used because accuracy saturates quickly on these tasks.

Results

Unless stated otherwise: an MLP with two hidden layers of 256 units, SGD, two binary MNIST tasks (A: 3 vs 5, B: 4 vs 9) and five seeds. Each run ends with 4000 steps without learning, so only consolidated memory remains: by then the labile part has decayed to under 2% of its value. The cross-task and log experiments use a separate output per task, so interference runs through the shared hidden layers.

Event timing determines what is kept

Without an event nothing is kept, and accuracy on A falls from 0.95 to 0.61 after the delay; near the event it stays at about 0.95. The two sides of the window have separate causes, as STC predicts: tag lifetime mainly shifts the after-side, and the lifetime of the plasticity-related products mainly shifts the before-side. Because capture needs both, the window's shape follows from the time constants built into the model, so this experiment confirms that the mechanism works inside gradient training rather than showing that a window emerges on its own. Without tags an event at +600 steps still keeps 51%, and size-triggered capture keeps 62% with no event at all, so later events cannot change what it keeps.

Cross-task rescue

When task B's onset is salient, it rescues task A retroactively; without salience neither task is kept. With one tag per weight, B's own learning re-tags weights shared with A, so binding each episode's change to its own tag is needed for a clean window. With per-weight tags B's event still captures 24% of A at a 900-step gap; with per-change tags nothing is captured at that gap.

The consolidation log as an explanation

Faithfulness is tested by deletion: parameters are ranked by the log's attribution, by Fisher importance, by the total change each task made to them, or at random, and the top-ranked ones are reset to their pre-learning values. Removing the 5% of parameters the log attributes to task A drops accuracy on A from 0.87 to 0.80 while sparing B; removing B's drops B from 0.97 to 0.69 while sparing A. Fisher importance separates the two memories far less clearly. Ranking by change size is a stronger baseline: for task A it matches the log (0.796 against 0.797), and only for task B does the log do better (0.691 against 0.764), so what consolidation adds to the explanation is visible for B.

Forgetting on Split-MNIST

Five binary tasks are learned in sequence. In the surprise-gated variants, an event fires when the training loss exceeds its running mean by three standard deviations, with settings fixed in advance and no task labels.

STC alone does not measurably reduce forgetting: it decides what becomes permanent, but consolidated weights are not protected from later learning. Using the consolidation log as importance in an EWC-style penalty reaches EWC level, with importance selected by surprising events after learning rather than fixed during it. It does not outperform Synaptic Intelligence. The detector also caught a task change within 20 steps in at most 3 of the 4 changes, so the result does not show that surprise picks the right moments.

Limitations

  • Small MLPs on MNIST only; the results demonstrate the mechanism, not performance at scale.
  • Time is measured in training steps, and time constants were set by hand.
  • The deletion test resets weights without retraining, and the surprise detector reacts to loss noise as well as to task changes.
  • The biological mapping is simplified: backprop is not a biological learning rule, and a hidden unit is not a neuron.
