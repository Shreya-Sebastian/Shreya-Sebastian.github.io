RetroSTC-Net

Can an event that happens after learning decide whether a network keeps what it learned? Retroactive consolidation for neural networks, based on synaptic tagging and capture.

Background

According to the synaptic tagging and capture (STC) hypothesis (Frey and Morris, 1997), learning first causes a short-lived synaptic change and leaves a temporary tag. The change becomes permanent only if plasticity-related products arrive while the tag is still present, and these can be triggered by a separate salient event. Behaviourally, a novel experience shortly before or after weak learning makes the weak memory last.

This project implements that mechanism in standard backprop-trained networks, tests whether the behavioural-tagging time window appears, and uses the network's own consolidation record as an explanation of what it remembers.

Contribution

Related mechanisms exist, such as a decaying weight component with tag-and-capture against forgetting (Leimer, Herzog and Senn, 2019) and retroactive STC in spiking networks (Lehr, Luboeinski and Tetzlaff, 2022). What this project adds:

  • consolidation in a backprop-trained network that is decided retroactively, by a salience event occurring after learning;
  • a behavioural-tagging time-window test in network weights, including rescue of one task by another;
  • a consolidation log that explains what the network retained, validated with a faithfulness test.

Method

Each weight is split into a consolidated part L and a labile part E, with effective weight w = L + E. The optimiser updates w as usual; after each step:

BiologyNetwork
Early-phase LTP decaysE ← E · exp(−1/τE)
Synaptic tagh ← h · exp(−1/τh) + |Δw|
Plasticity-related products, shared per neuronp ← p · exp(−1/τp) + α·s(t)
Capturec = clamp(κ · p · [h > θ], 0, 1), then L += c·E, E −= c·E
Salient events(t): a pulse, or a sudden jump in training loss

Labile change is tracked per learning episode, so every consolidated change can be traced to the task that produced it and the event that captured it.

Results

Unless stated otherwise: an MLP with two hidden layers of 256 units, SGD, two binary MNIST tasks (A: 3 vs 5, B: 4 vs 9) and five seeds. Each run ends with 4000 steps without learning, so only consolidated memory remains.

Event timing determines what is kept

Without an event nothing is kept, and accuracy on A falls from 0.95 to 0.61 after the delay; near the event it stays at about 0.95. The two sides of the window have separate causes, as STC predicts: tag lifetime shifts only the after-side, and the lifetime of the plasticity-related products shifts only the before-side.

Cross-task rescue

When task B's onset is salient, it rescues task A retroactively; without salience neither task is kept. With one tag per weight, B's own learning re-tags weights shared with A, so binding each episode's change to its own tag is needed for a clean window.

The consolidation log as an explanation

Faithfulness is tested by deletion: parameters are ranked by the log's attribution, by Fisher importance or at random, and the top-ranked ones are reset to their pre-learning values. Removing the 5% of parameters the log attributes to task A drops accuracy on A from 0.87 to 0.80 while sparing B; removing B's drops B from 0.97 to 0.69 while sparing A. Fisher importance separates the two memories far less clearly.

STC alone barely reduces forgetting: it decides what becomes permanent, but consolidated weights are not protected from later learning. Using the consolidation log as importance in an EWC-style penalty reaches EWC level, with importance selected by surprising events after learning rather than fixed during it. It does not outperform Synaptic Intelligence.

Limitations

  • Small MLPs on MNIST only; the results demonstrate the mechanism, not performance at scale.
  • Time is measured in training steps, and time constants were set by hand.
  • The biological mapping is simplified: backprop is not a biological learning rule, and a hidden unit is not a neuron.
