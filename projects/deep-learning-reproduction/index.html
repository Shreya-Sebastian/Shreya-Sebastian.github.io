Deep Learning · TU Delft

Deep learning paper reproduction

A reproduction of “Multi-view underwater image enhancement method via embedded fusion mechanism” for the CS4240 Deep Learning course.

Overview

A team of four reproduced a published method for underwater image enhancement that fuses several pre-processed views of the same image, such as white-balanced and contrast-enhanced (CLAHE) versions, inside the network.

My part

  • Built the model architecture.
  • Contributed to data preprocessing.
  • Wrote the technical blog post on what did and did not replicate.

Other team members built the training loop and loss function, the evaluation metrics and inference, and the white balance and CLAHE functions.

Type
Group project, Deep Learning course (CS4240), TU Delft
My role
Model architecture, data preprocessing, blog post
