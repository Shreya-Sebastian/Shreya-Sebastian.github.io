3D CNNs for pollen classification

Does classifying pollen from full 3D microscope stacks beat working from 2D projections of the same images?

Overview

Pollen grains are imaged under the microscope as Z-stacks, series of images at different focal depths. Earlier work on automatic classification of Urticaceae pollen used 2D projections of these stacks. This thesis builds on that work and asks whether models that see the full 3D stack do better.

Approach

  • Implemented a custom ConvNet3D and a torchvision ResNet3D in PyTorch.
  • Trained them on about 600 raw Z-stacks of variable size, and compared them with models trained on 2D projections of the same data.

Result

The best model reached 95 percent test accuracy.

The project builds on Analysis of automatic image classification methods for Urticaceae pollen classification.
